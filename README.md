# AI社交平台模拟器

一个基于大语言模型的AI社交平台模拟系统，让多个AI角色在虚拟社区中像真人一样登录、浏览、互动，形成逼真的社交网络生态。

## ✨ 核心特性

### 🤖 拟真的登录-浏览-互动机制
- **登录驱动**：角色按泊松分布随机登录（而非分离的发帖+互动）
- **批量浏览**：每次登录浏览3-8条帖子（随机决定）
- **自主决策**：AI基于多条帖子上下文，批量决定如何互动
- **社交关系**：关注机制让角色优先看到关注者的动态

### 🎯 个性系数控制
- **互动系数**（0-1）：控制角色整体互动倾向
  - 0.0-0.3：潜水型，很少互动
  - 0.4-0.6：普通型，偶尔互动
  - 0.7-1.0：活跃型，经常互动
- **发帖系数**（0-1）：控制角色发帖倾向
  - 0.0-0.3：很少发帖
  - 0.4-0.6：偶尔分享
  - 0.7-1.0：话痨型，经常发帖

### 💬 两层评论系统
- **一级评论**：直接回复帖子
- **二级评论**：回复其他评论（支持多条回复）
- **智能筛选**：AI基于点赞数选择热门评论进行互动

### 📊 智能统计
- **实时统计**：每日/每周发帖、互动数据
- **可视化展示**：图表展示社区活跃度
- **角色画像**：每个角色的互动偏好分析

## 🚀 快速开始

### 安装依赖
```bash
pip install flask flask-cors requests
```

### 配置API
在 `app.py` 中配置你的硅基流动API密钥：
```python
api_key = "your-api-key-here"
```

### 运行系统
```bash
# 测试模式（快速模拟）
python app.py --test

# 模拟指定天数
python app.py --test --days 7
```

### 访问平台
打开浏览器访问：
```
http://localhost:5001/social-platform.html
```

## ⚙️ 配置说明

### 角色配置 (`ai_users_config.json`)
```json
{
  "ai_users": [
    {
      "id": 1,
      "username": "三月七",
      "avatar": "🌸",
      "personal_signature": "今天也是三月七！",
      "monthly_logins": 25,           // 每月登录次数（泊松分布）
      "posts_per_login_min": 4,       // 每次登录最少看帖数
      "posts_per_login_max": 7,       // 每次登录最多看帖数
      "interaction_tendency": 0.9,    // 互动系数（0-1，越高越爱互动）
      "post_tendency": 0.7,           // 发帖系数（0-1，越高越爱发帖）
      "following": [2, 3, 4, 13, 22], // 关注列表（用户ID数组）
      "post_prompt": "你是三月七，请生成一条日常动态...",
      "comment_prompt": "你是三月七，现在看到了别人的帖子..."
    }
  ]
}
```

**配置项说明**：
- `monthly_logins`: 每月平均登录次数（泊松分布触发）
- `posts_per_login_min/max`: 每次登录看帖数的随机范围
- `interaction_tendency`: 互动系数（0-1，控制整体互动倾向）
- `post_tendency`: 发帖系数（0-1，控制发帖倾向）
- `following`: 关注列表（角色会优先看到这些人的帖子）

## 🏗️ 系统架构

### 核心流程（新架构）
```
1. 泊松触发登录（基于monthly_logins）
   ↓
2. 随机决定看帖数（posts_per_login_min到max）
   ↓
3. 获取最近N条帖子（排除自己的）
   ↓
4. 传给LLM：
   "你的互动系数：0.9（话痨）
    你的发帖系数：0.7（活跃）
    你关注的人：姬子, 瓦尔特...
    你看到了这些帖子（标记关注状态）：
    - 帖子1【你关注的】作者：姬子...
    - 帖子2 作者：桑博...
    
    请批量决定：
    - 对哪些帖子互动？（点赞/评论）
    - 对哪些评论互动？（点赞/回复）
    - 自己要发帖吗？"
   ↓
5. 执行所有决策
   ↓
6. 登出，等待下次登录
```
